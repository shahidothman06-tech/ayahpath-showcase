# AyahPath — Quran Reading Companion

**Never lose your place. Never lose your connection.**

## About the Project

AyahPath is a Quran reading companion designed to help users remember exactly where they stopped reading, making it easier to continue their Quran journey whenever they return.

## Key Features

- **Reading Progress:** Keep track of your last-read Surah and Ayah.
- **Audio Recitation:** Support for Quran audio playback.
- **Translations:** Help users understand Quranic verses.
- **Reading Experience:** A clean, modern, and minimal interface.
- **Personal Settings:** Customize the reading experience.

## Technology Stack

- Kotlin
- Android
- Jetpack Compose
- Firebase (planned or used, depending on implementation)

## Project Goals

- Make Quran reading more consistent.
- Help users resume reading without searching for their last position.
- Deliver a simple and accessible mobile experience.

In development / prototype.
